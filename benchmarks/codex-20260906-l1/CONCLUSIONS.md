# L1 两题三组对照结论

日期: 2026-09-08. 本轮已完成, 6 份求解交付和 6 次外部盲审均已冻结.

旧版 A, 新版 B, 空白 C 在两道题上均获外部盲审 PASS, 100/100, 没有实质证明缺口或补证. 空白 C 在每道题上都以更低的实际完整交付成本达到同样的审计评分. 新版没有达到本轮预设的性能优化目标.

这支持停止宣称新版已经提高求解效率. 它不证明插件一般无用, 也不否定文献工具库和恢复功能的作用. 本轮是两个已知开发题的单次回归, 使用同一模型 Astra/max; 存在自然额度中断, 缓存变化, 协调器快照过期, 认证恢复和账号/套餐切换, 无法把成本差异全部归因于插件.

## 恢复与基础设施

自然额度中断后, A/B 均沿原会话和剩余预算续接, 已返回工件没有丢失. T2 B 外审还发生一次协调器额度快照过期暂停, 单独记录, 没有冒充真实额度耗尽或新版恢复收益. 新版与旧版都观察到可续接, 因此这些经历不能替代新版恢复功能的受控验收.

T2 A 续接时, 当前桌面账号已切换到 Pro. 接口只报告一个 10080 分钟窗口, secondary 为 null. 运行器已改为按实际返回的窗口检查额度, 没有伪造五小时百分比, 也没有把 null 当作 0 或无限. 保留旧 seal, 记录新旧运行器哈希, 题目/模型/插件/隔离配置不变, 未兑换重置积分. C 使用同一当前桌面账号启动. 账号切换是本轮的额外比较限制.

完整核验重新检查了 12 个阶段的冻结哈希, 题目与答案绑定, 实际模型/推理强度, 评分一致性, 285 个唯一响应的用量及运行进程已退出. 未知的在途用量, 完整嵌套工具调用数, 根与子任务合计运行时间及首次证明时间仍为未知. 本轮不声称 Lean 形式化验证或新颖性, 不修改主项目的 accepted 数学状态.
