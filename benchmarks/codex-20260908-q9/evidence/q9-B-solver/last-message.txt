Write \(t=\sqrt r\), so \(0<t<c<1\).

### 1. The range \(t\le c/2\)

C2 says \(H_m(g)=c(\pi/2-H_m(d))\). Strict convexity of tangent gives
\[
m\tan g
<c\tan(\pi/2-H_m(d))
=\frac{c}{m\tan d}.
\]
The arguments lie in \((0,\pi/2)\). Since \(\tan d=t\sin g/\cos d\),
\[
m^2t\sin^2g<c\cos g\cos d<c,
\qquad k\sin^2g<c/t.
\tag{2}
\]

Sine concavity implies \(\arcsin(t\sin z)\le tz\) for \(0<z<\pi/2\). Thus C3 gives
\[
B-g\le ct(B+g),\qquad
\frac Bg\le\frac{1+ct}{1-ct}.
\]
Since \(\sin z/z\) strictly decreases,
\[
\frac{\sin B}{\sin g}<\frac{1+ct}{1-ct}.
\]
Consequently, when \(t\le c/2\),
\[
ke t^2\sin^2B
<ec t\left(\frac{1+ct}{1-ct}\right)^2
\le\frac{ec^2}{2}\left(\frac{2+c^2}{2-c^2}\right)^2
<\frac{3c^2}{4}
\le c^2-t^2.
\tag{3}
\]
The penultimate strict inequality follows from the exact identity
\[
3(2-x)^2-2(1-x)(2+x)^2=(3x-2)^2+2x^3>0,
\qquad x=c^2.
\]

### 2. Excluding \(t\ge c/2\) when \(Q_{\rm quad}>0\)

Suppose \(Q_{\rm quad}>0\) and \(c/2\le t<c\). Define
\[
X=\tan B,\quad z=\tan g,\quad h=mz,
\]
\[
L=\sqrt{1+(1-t^2)X^2},\quad
w=\sqrt{1+(1-t^2)z^2},\quad u=ct,
\]
\[
a=c(1+(c^2+2)t^2),\quad
b=t(1+2c^2+c^2t^2),\quad
J=\frac{49}{100}(1+c)^2,\quad
j=\frac{Jw^2}{(w+u)^2}.
\]

Strict sine concavity and exact C3 imply
\[
\sin(B-g)>c\sin(A+d),
\]
hence, after multiplication by a positive common denominator,
\[
X-z>u(Xw+zL).
\tag{4}
\]
Therefore \(1-uw>0\) and \(X/z>(1+uL)/(1-uw)\). Squaring this positive inequality gives
\[
\begin{aligned}
0&<(L^2-1)(1-uw)^2-(w^2-1)(1+uL)^2\\
&=(L+w)\bigl((1+u^2)(L-w)-2u(Lw-1)\bigr).
\end{aligned}
\]
Set
\[
D=1+u^2-2uw,\qquad N=(1+u^2)w-2u.
\]
Since \(N>(1-u)^2>0\), this proves \(D>0\) and \(L>N/D\).

The first term of \(Q_{\rm quad}\) is \(P=(c-tL)/X\). Its subtracted term is strictly positive, so \(c-tL>0\). Using (4) and the strictly decreasing function \((c-t\ell)/(1+u\ell)\),
\[
0<Pz<
\frac{(c-tL)(1-uw)}{1+uL}
<
\frac{cD-tN}{1-u^2}
=\frac{a-bw}{1-u^2}=:f.
\tag{5}
\]
Thus
\[
1<w<a/b,\qquad a-b=(c-t)(1-ct)^2>0.
\tag{6}
\]

Next, exact C2 and strict concavity of arctangent give
\[
\frac{c\pi}{2(1+c)}
=\frac{c\arctan(th/w)+\arctan h}{1+c}
<
\arctan\!\left(\frac{h(1+ct/w)}{1+c}\right).
\]
The Jensen weights are positive, and its inputs differ because \(t/w<1\). Since \(c\ge2/3\), the left side is at least \(\pi/5\). Hence
\[
h>\frac{(1+c)w}{w+ct}\tan(\pi/5)
>\frac7{10}\frac{(1+c)w}{w+ct},
\qquad h^2>j.
\tag{7}
\]
The rational bound used here is exact: for \(\theta=\arctan(7/10)\),
\[
\frac{\sin5\theta}{\cos^5\theta}=\frac{23807}{100000}>0,\qquad
\frac{\cos5\theta}{\cos^5\theta}=-\frac{5399}{2000}<0.
\]
Because \(0<5\theta<5\pi/4\), these signs imply \(5\theta<\pi\).

Direct substitution in the original definition of \(Q_{\rm quad}\) yields
\[
Q_{\rm quad}z=Pz-K(h^2),
\]
where
\[
K(x)=
\frac{c(1-t^2)^2(x-z^2)}
{1+uw+x(1+ut^2/w)}.
\]
For \(x\ge0\), this denominator is positive and \(K'(x)>0\).

The following polynomial inequality is certified exactly below:
\[
\begin{aligned}
E={}&c(1-t^2)(1-u^2)
\bigl((1-t^2)Jw^2-(w^2-1)(w+u)^2\bigr)\\
&-(a-bw)\bigl((1+uw)(w+u)^2+Jw(w+ut^2)\bigr)\ge0
\end{aligned}
\tag{8}
\]
throughout
\[
2/3\le c<1,\qquad c/2\le t<c,\qquad 1\le w\le a/b.
\]
Since \(z^2=(w^2-1)/(1-t^2)\), direct common-denominator calculation gives
\[
K(j)-f=
\frac{E}
{(1-u^2)\bigl((1+uw)(w+u)^2+Jw(w+ut^2)\bigr)}
\ge0.
\]
Every denominator factor is positive. Equations (5) and (7) now imply
\[
Q_{\rm quad}z<f-K(h^2)<f-K(j)\le0,
\]
a contradiction. Thus \(Q_{\rm quad}>0\Rightarrow t<c/2\).

### 3. Exact certificate for (8)

Put \(s=t/c\in[1/2,1)\) and
\[
\alpha=1+(c^4+2c^2)s^2,\quad
\beta=s(1+2c^2+c^4s^2),\quad
\delta=(1-s)(1-c^2s)^2=\alpha-\beta.
\]
Here \(\beta,\delta>0\), and every required \(w\) has the form
\[
w=1+\frac{\delta}{\beta}\zeta,\qquad 0\le\zeta\le1.
\]
The expression
\[
F(c,s,\zeta)=\frac{100\beta^4}{c}
E\!\left(c,cs,1+\frac{\delta}{\beta}\zeta\right)
\]
is an integer polynomial of respective degrees \((26,18,4)\). Define
\[
G(\xi,\eta,\zeta)=3^{26}2^{18}
F\!\left(\frac{2+\xi}{3},\frac{1+\eta}{2},\zeta\right).
\]

For \(B_i^n(x)=\binom ni x^i(1-x)^{n-i}\), the binomial theorem gives
\[
x^p=\sum_{i=p}^n
\frac{\binom ip}{\binom np}B_i^n(x).
\]
Applying this identity in all three variables expresses \(G\) in a basis nonnegative on \([0,1]^3\).

The complete integer checker below verifies that its 2,565 Bernstein coefficients comprise **2,535 positive coefficients and 30 zeros**, after multiplication by a common positive integer. It also inverts the basis change and checks the polynomial identity exactly. Therefore \(G\ge0\), and the positive scaling factors prove (8). This is a certificate over the entire continuous domain, not a finite scan.

```python
from collections import defaultdict
from math import comb, lcm

class P(dict):
    def __add__(a, b):
        if not isinstance(b, P): b = P({(0, 0, 0): b})
        d = P(a)
        for k, v in b.items(): d[k] = d.get(k, 0) + v
        return P({k: v for k, v in d.items() if v})
    __radd__ = __add__
    def __neg__(a): return P({k: -v for k, v in a.items()})
    def __sub__(a, b): return a + -b
    def __rsub__(a, b): return -a + b
    def __mul__(a, b):
        if not isinstance(b, P):
            return P({k: v*b for k, v in a.items() if v*b})
        d = defaultdict(int)
        for (i,j,k), v in a.items():
            for (l,m,n), w in b.items(): d[i+l,j+m,k+n] += v*w
        return P({k: v for k, v in d.items() if v})
    __rmul__ = __mul__
    def __pow__(a, n):
        r = P({(0, 0, 0): 1})
        while n:
            if n & 1: r = r*a
            a = a*a
            n //= 2
        return r

c, s, z = (P({e: 1}) for e in ((1,0,0),(0,1,0),(0,0,1)))
t2, u = c*c*s*s, c*c*s
A = 1 + (c**4 + 2*c*c)*s*s
B = s*(1 + 2*c*c + c**4*s*s)
D = (1-s)*(1-u)**2
assert A-B == D
W, J100 = B + D*z, 49*(1+c)**2
V = W + u*B
F = ((1-t2)*(1-u*u)*((1-t2)*J100*W*W*B*B
     - 100*(W*W-B*B)*V*V)
     - D*(1-z)*(100*B*(B+u*W)*V*V
     + J100*W*(W+u*t2*B)*B*B))
N = (26,18,4)
assert tuple(max(e[a] for e in F) for a in range(3)) == N
assert len(F) == 637

# Exact affine substitution, with denominators cleared.
G = defaultdict(int)
for (a,b,k), v in F.items():
    for i in range(a+1):
        vi = v*comb(a,i)*2**(a-i)*3**(26-a)
        for j in range(b+1):
            G[i,j,k] += vi*comb(b,j)*2**(18-b)
G = {e: v for e, v in G.items() if v}
assert len(G) == 2103

# Bernstein coefficients multiplied by a positive common scale.
C, L = G, 1
for axis, n in enumerate(N):
    ell = lcm(*(comb(n,i) for i in range(n+1)))
    L *= ell
    out = defaultdict(int)
    for e, v in C.items():
        i = e[axis]
        for k in range(i,n+1):
            f = list(e); f[axis] = k
            out[tuple(f)] += v*comb(k,i)*(ell//comb(n,i))
    C = dict(out)

index = [(i,j,k)
         for i in range(27) for j in range(19) for k in range(5)]
values = [C.get(e,0) for e in index]
assert len(values) == 2565
assert sum(v > 0 for v in values) == 2535
assert sum(v == 0 for v in values) == 30
assert all(v >= 0 for v in values)
assert all(C[i,j,k] > 0 for i,j,k in index if i == 0)
assert all((C.get((i,j,k),0) == 0) == (i+j >= 42)
           for i,j,k in index)

# Invert the basis change and verify the exact polynomial identity.
back = C
for axis, n in enumerate(N):
    out = defaultdict(int)
    for e, v in back.items():
        k = e[axis]
        for i in range(k,n+1):
            f = list(e); f[axis] = i
            out[tuple(f)] += (
                v*comb(n,k)*comb(n-k,i-k)*(-1)**(i-k))
    back = {e: v for e, v in out.items() if v}
assert back == {e: v*L for e, v in G.items()}
print("PASS: exact identity; 2535 positive coefficients, 30 zero.")
```

### 4. Q9 follows strictly
