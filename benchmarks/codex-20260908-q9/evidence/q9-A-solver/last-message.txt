Here is the proof, including a precise description of its finite rational certificate.

Put \(s=\sqrt r\), \(w=k\sin^2g\), and
\[
X=\cot B,\qquad Y=\cot g,\qquad
K=\frac{1+cs}{1-cs}.
\]
Thus \(0<s<c<1\). All original hypotheses, including the three simultaneous constraints, remain assumed.

For \(a(z)=\arcsin(s\sin z)\),
\[
0<a'(z)=\frac{s\cos z}{\sqrt{1-s^2\sin^2z}}\le s.
\]
Consequently (C3) gives \(B/g\le K\). Since \(\sin z/z\) decreases on \((0,\pi/2)\),
\[
\frac{\sin B}{\sin g}\le K. \tag{1}
\]

Strict concavity of sine, applied to \(0<A+d<\pi\), gives
\[
\sin(B-g)=\sin(c(A+d))>c\sin(A+d).
\]
Expanding and dividing by \(\sin B\sin g>0\) yields
\[
Y-X>cs\left(\sqrt{Y^2+1-s^2}+\sqrt{X^2+1-s^2}\right). \tag{2}
\]
In particular,
\[
\frac XY<\frac{1-cs}{1+cs}.
\]
Writing
\[
f=cX-s\sqrt{X^2+1-s^2},
\]
we obtain
\[
f\tan g<L:=\frac{(c-s)(1-cs)}{1+cs}.
\]

Set \(\rho=s\cos g/\cos d<s\). The original definition of \(Q_{\rm quad}\) gives exactly
\[
Q_{\rm quad}\tan g
=f\tan g-\frac{c(1-s^2)^2w}{1+w+c\rho(1+s^2w)}.
\]
Therefore \(Q_{\rm quad}>0\) implies
\[
L>\frac{c(1-s^2)^2w}{1+cs+(1+cs^3)w}.
\]
Define
\[
P=1+2c^2-3cs-3c^2s^2+c(2+c^2)s^3.
\]
Here \(P>0\): its derivative in \(s\) is
\[
P_s=3c\bigl((2+c^2)s^2-2cs-1\bigr)<0
\quad(0\le s\le c),
\]
because the bracket is convex with negative endpoint values \(-1,c^4-1\). Hence
\[
P\ge P(c,c)=(1-c^2)(1-c^4)>0.
\]
Rearranging the preceding inequality now gives
\[
w<W:=\frac{(c-s)(1-c^2s^2)}{sP}. \tag{3}
\]

For \(0<s\le12/25\), combining (1) and (3) gives
\[
\frac{ker\sin^2B}{c^2-r}
<
\frac{(1-c^2)s(1+cs)^3}{(c+s)(1-cs)P}.
\]
The polynomial
\[
E=(c+s)(1-cs)P-(1-c^2)s(1+cs)^3
\]
is strictly positive on
\[
\frac23\le c\le1,\qquad 0\le s\le\frac{12}{25}.
\]
An exact Bernstein certificate proving this is given below. Thus \(S>0\) in this range.

It remains to exclude \(s\ge12/25\) when \(Q_{\rm quad}>0\). The latter implies \(f>0\), so
\[
X>\frac{s\sqrt{1-s^2}}{\sqrt{c^2-s^2}}.
\]
Using (2) and the strictly increasing function
\(y\mapsto y-cs\sqrt{y^2+1-s^2}\), we obtain
\[
Y>
Y_0:=
\frac{s\sqrt{1-s^2}(1+2c^2+c^2s^2)}
{(1-c^2s^2)\sqrt{c^2-s^2}}.
\]
The positive inverse branch is checked by substitution; all radicals and denominators here are positive.

Define
\[
\Lambda=Y_0^{-2},\qquad
Z=W+(1+W)\Lambda,\qquad
D=\frac{s^2Z}{1+(1-s^2)\Lambda}.
\]
With \(z=m\tan g\), \(t=m\tan d\), and \(\ell=Y^{-2}<\Lambda\), the exact identities

z^2=w+(1+w)\ell,\qquad
t^2=\frac{s^2\{w+(1+w)\ell\}}{1+(1-s^2)\ell}

z^2<Z,\qquad t^2<D. \tag{4}

Both expressions increase in \(w,\ell\); for the second, its derivative in \(\ell\) is

To specify the finite certificate completely, put
\[
\begin{aligned}
J&=1-c^2s^2,&N_w&=(c-s)J,&D_w&=sP,\\
N_\ell&=J^2(c^2-s^2),&
D_\ell&=s^2(1-s^2)(1+2c^2+c^2s^2)^2,\\
N_z&=N_wD_\ell+(D_w+N_w)N_\ell,&D_z&=D_wD_\ell,\\
N_t&=s^2N_z,&D_t&=D_w\{D_\ell+(1-s^2)N_\ell\}.
\end{aligned}
\]
Then \(Z=N_z/D_z\), \(D=N_t/D_t\), with positive denominators. Each table row is certified by
\[
z_0^2D_z-N_z\ge0,\qquad t_0^2D_t-N_t\ge0.
\]

For a polynomial \(p(u,v)=\sum p_{ab}u^av^b\) of bidegree \((n,m)\), its Bernstein coefficients are exactly
\[
\beta_{ij}=\sum_{a\le i,\ b\le j}
p_{ab}\frac{\binom ia}{\binom na}\frac{\binom jb}{\binom mb}.
\]
This follows from the binomial theorem identity
\[
u^a=\sum_{i=a}^n\frac{\binom ia}{\binom na}
\binom ni u^i(1-u)^{n-i}.
\]
Nonnegative Bernstein coefficients prove nonnegativity on the entire unit square.

from fractions import Fraction as F
from math import comb

def add(*ps):
    q = {}
    for p in ps:
        for ij, a in p.items():
            q[ij] = q.get(ij, F(0)) + a
    return {ij: a for ij, a in q.items() if a}

def scale(p, a):
    return {ij: a*b for ij, b in p.items() if a*b}

def sub(p, q):
    return add(p, scale(q, -1))

def mul(p, q):
    r = {}
    for (i, j), a in p.items():
        for (k, l), b in q.items():
            ij = (i+k, j+l)
            r[ij] = r.get(ij, F(0)) + a*b
    return {ij: a for ij, a in r.items() if a}

def power(p, n):
    q = {(0, 0): F(1)}
    for _ in range(n):
        q = mul(q, p)
    return q

def substitute(p, C, S):
    cp = [power(C, i) for i in range(max(i for i,j in p)+1)]
    sp = [power(S, j) for j in range(max(j for i,j in p)+1)]
    return add(*(scale(mul(cp[i], sp[j]), a)
                 for (i, j), a in p.items()))

def bernstein(p):
    n = max(i for i,j in p)
    m = max(j for i,j in p)
    b = [[sum((a*F(comb(i,k),comb(n,k))*F(comb(j,l),comb(m,l))
               for (k,l),a in p.items() if k<=i and l<=j), F(0))
          for j in range(m+1)] for i in range(n+1)]
    return n, m, b

one = {(0,0): F(1)}
c = {(1,0): F(1)}
s = {(0,1): F(1)}
c2, s2 = power(c,2), power(s,2)
cs = mul(c,s)
P = add(one, scale(c2,2), scale(cs,-3),
        scale(mul(c2,s2),-3),
        mul(mul(c,add(scale(one,2),c2)),power(s,3)))
E = sub(mul(mul(add(c,s),sub(one,cs)),P),
        mul(mul(sub(one,c2),s),power(add(one,cs),3)))

# Small-s certificate: c=(2+u)/3, s=12v/25.
C = add(scale(one,F(2,3)),scale(c,F(1,3)))

n,m,b = bernstein(substitute(E,C,S))

 [1650390625,1534140625,1300215625,966327625,571546705,138478561],
 [2050781250,1891406250,1603781250,1216202250,781848450,330011178],
 [2548828125,2329453125,1972378125,1522315125,1052902845,604001061],
 [3164062500,2860312500,2410762500,1885396500,1387790820,974492532]]
assert (n,m)==(4,5)
assert all(b[i][j]==F(N[i][j],1054687500)>0
           for i in range(5) for j in range(6))

# Complementary certificate.
J = sub(one,mul(c2,s2))
Nw, Dw = mul(sub(c,s),J), mul(s,P)
Nl = mul(power(J,2),sub(c2,s2))
Dl = mul(mul(s2,sub(one,s2)),
         power(add(one,scale(c2,2),mul(c2,s2)),2))
Nz = add(mul(Nw,Dl),mul(add(Dw,Nw),Nl))
Dz = mul(Dw,Dl)
Nd = mul(s2,Nz)
Dd = mul(Dw,add(Dl,mul(sub(one,s2),Nl)))

# c lower, c upper, s lower, s upper (None means c), z bound, t bound.
rows = [
 (F(2,3),F(7,10),F(12,25),None,F(19,20),F(21,50)),
 (F(7,10),F(3,4),F(12,25),None,F(101,100),F(9,20)),
 (F(3,4),F(1),F(12,25),F(3,5),F(27,25),F(1,2)),
 (F(3,4),F(1),F(3,5),None,F(9,10),F(3,5))]
expected = [((19,12),(19,13)),((19,12),(19,13)),
            ((9,12),(9,13)),((19,12),(19,13))]
count = zero_count = 0
for row_number,(a,b,t,h,z,d) in enumerate(rows):
    C = add(scale(one,a),scale(c,b-a))
